# 驻波数值仿真 (Standing Wave)

**原理简介**：两列频率相同、振动方向相同、传播方向相反的简谐行波叠加，就形成驻波。本演示把入射波 `y₁ = A₁sin(kx − ωt)` 与反射波 `y₂ = A₂sin(kx + ωt)` 逐点相加，实时呈现合成波形。

关键在于**振幅不等时的行驻波混合态**：严格驻波要求 A₁ = A₂，一旦不等，叠加结果里就多出一列净能流不为零的行波分量，波节不再完全静止，而是以 `|A₁ − A₂|` 为振幅上下颤动。页面用驻波比 VSWR = (A₁+A₂)/|A₁−A₂| 定量刻画这种偏离程度。

数值上采用解析解的离散采样：和角公式展开后 `y = P·sin(kx)·cos(ωt) + Q·cos(kx)·sin(ωt)`，其中 P = A₁+A₂、Q = A₂−A₁，sin(kx) 与 cos(kx) 预计算成数组，每帧只需 2 次三角函数，其余全是 Float64Array 上的乘加运算，900 个采样点稳定跑满 60fps。
