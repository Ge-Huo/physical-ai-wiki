# 体感音符 - 手机传感器控制实验

## 实验概述
本实验利用手机内置的加速度传感器和陀螺仪，通过 HTML5 的 `DeviceOrientationEvent` API 实时采集手机倾斜角度，并将其映射为 Web Audio API 合成音符的触发与包络控制指令。您需要通过平稳倾斜手机来演奏纯净的正弦波音符，验证体感交互在音频反馈中的延迟、平滑度与心理预期匹配度，体验沉浸式的体感音乐交互。

## 实验原理
1. **传感器数据**：利用 `deviceorientation` 事件获取手机的 **β（前后倾斜）** 或 **γ（左右倾斜）** 角度作为单一控制轴。
2. **信号处理**：对原始角度数据进行死区过滤与指数移动平均（EMA）低通滤波，消除手持抖动噪声并保留动作趋势。
3. **音频合成**：使用 Web Audio API 的 `OscillatorNode` 生成 440Hz 正弦波，通过 `GainNode` 的线性渐变实现 Attack/Release 包络，避免爆音并塑造音色质感。
4. **挑战机制**：
   - **触发阈值**：平滑后的角度绝对值超过 25° 时触发音符，低于阈值时释放静音。
   - **零位校准**：启动后需静置 1~2 秒让滤波器收敛，建立稳定的触发基准。
   - **成功标准**：能够稳定、可预测地通过身体动作控制音符的发声与停止，且感知延迟 < 100ms。

## 操作步骤
1. 点击上方按钮打开体感音符应用。
2. **首次使用**：点击「▶ 启动传感器」按钮，允许浏览器获取设备方向权限（iOS 会弹出授权框，请允许）。
3. **校准**：将手机水平静置 1~2 秒，待状态栏显示“✅ 就绪”后即可开始演奏。
4. **控制音符**：向前/后（或左/右，取决于配置）倾斜手机，超过阈值时触发 440Hz 音符；回正时音符以 100ms 释音衰减至静音。
5. **观察反馈**：
   - 绿色指示条实时反映滤波后的倾斜角度，白色标记线标示触发阈值边界。
   - 状态文字显示当前触发状态与精确角度值，帮助建立动作-声音的心理映射。
6. **备选操控**：电脑上可使用鼠标拖拽指示条或键盘空格键模拟触发，无需传感器。
7. **调参与重置**：若手感不佳，可修改源码顶部 `CONFIG` 对象中的参数（如 `threshold`、`smoothing`），刷新页面即可生效。

## 注意事项
- 传感器数据在手机静止时最稳定，剧烈抖动可能导致误触发，建议平稳握持或置于桌面测试。
- 如果声音有爆音或突兀感，可尝试增大 `attackTime` 和 `releaseTime` 参数，具体见代码注释。
- iOS 用户必须使用 Safari 浏览器，Chrome/Firefox on iOS 不支持传感器 API；Android 用户需在系统设置中确认浏览器已开启传感器权限。
- 本应用纯本地运行，不上传任何传感器数据，断网可用。
