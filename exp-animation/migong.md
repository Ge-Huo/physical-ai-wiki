# 体感迷宫 - 手机传感器控制实验

## 实验概述
本实验利用手机内置的加速度传感器和陀螺仪，通过 HTML5 的 `DeviceOrientationEvent` API 实时采集手机倾斜角度，并将其映射为 3D 迷宫中小球的运动控制指令。您需要通过倾斜手机引导小球在复杂迷宫中滚动，在限定时间和步数内到达终点，体验沉浸式的体感交互。

## 实验原理
1. **传感器数据**：利用 `deviceorientation` 事件获取手机的 **β（前后倾斜）** 和 **γ（左右倾斜）** 角度。
2. **控制映射**：将倾斜角度映射为小球在水平面上的加速度矢量，倾斜越大，加速度越大。
3. **物理模拟**：使用简单的牛顿力学（加速度、速度、摩擦、碰撞）模拟小球在迷宫中的滚动，碰撞墙壁时反弹并消耗能量。
4. **挑战机制**：
   - **时间限制**：60 秒倒计时，超时则挑战失败。
   - **步数限制**：最多 300 步（每一步为有效移动），超限则失败。
   - **胜利条件**：在限制内到达终点 🏁。

## 操作步骤
1. 点击上方按钮打开迷宫游戏。
2. **首次使用**：允许浏览器获取设备方向权限（iOS 会弹出授权框，请允许）。
3. **校准**：将手机平放在桌面上，保持静止 1~2 秒，界面会提示“校准中...”，完成后即可开始。
4. **控制小球**：向前/后/左/右倾斜手机，小球会向对应方向加速滚动。倾斜角度越大，速度越快。
5. **观察反馈**：
   - 顶部状态栏显示**剩余时间**、**已用步数**（上限 300）和**进度百分比**。
   - 终点有脉动光效，到达后触发庆祝粒子特效。
6. **备选操控**：电脑上可使用键盘 **WASD** 或**方向键**控制小球，无需传感器。
7. **失败与重来**：若超时或步数用尽，游戏会弹出失败提示，点击“重新挑战”即可重置。

## 注意事项
- 传感器数据在手机静止时最稳定，剧烈抖动可能导致误触，建议平稳握持。
- 如果游戏体验不顺畅，可尝试在设置中调整物理参数（如 `maxSpeed`、`friction`），具体见代码注释。
- 迷宫地图可自定义（修改 `MAZE` 二维数组），以增加或降低难度。
